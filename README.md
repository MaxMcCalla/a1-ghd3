Assignment 1 - Hello World: GitHub and d3  
===

Description
===
In this assignment, I started with simply drawing shapes and paths, then added functionality for interacting with the paths.
I chose to implement arcs and brushes in this assignment because they were two features I was curious about and would be expecting to use in future assignments.
The black rectangle on the bottom acts as a map for the arc on the top. The arc will respond to input on the square and update to match the input area.
